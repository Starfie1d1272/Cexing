# ADR 0004：分离规则所有权、候选范围与选点算法

状态：接受。日期：2026-10-15。

原四模板把地区、AI 服务和选点算法放在互斥层级，不能表达多国 Smart 与服务 fallback 的组合。采用两种规则所有权及独立出口/服务意图，默认沿用订阅；推荐须显式应用。高级定义编辑与原始配置仍保留。

所有生成继续使用现有配置事务、编辑绑定和版本来源，不新增发布器。旧模板保留兼容解释器及归档，不在升级时改变用户规则。服务分类复用固定版本的维护规则库，离线随包，避免几条域名形成错误完整性承诺。

准确默认值、优先级、冲突和验收见[组合分流契约](../reference/routing-intent.md)。本决定取代 ADR 0003 的新用户产品入口；旧地区生成的安全边界与恢复行为继续有效。
