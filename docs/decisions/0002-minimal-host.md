# ADR 0002：精简宿主并保留必要迁移入口

状态：接受。日期：2026-10-12。补充 ADR 0001。

## 背景

旧产品包含四 Tab、离线 YAML 节点模型、节点详情、连接/日志界面、桌面卡片和多套视觉方案。首页与应用入口同时触发后台服务。目标面板与原生实现存在重复，但导入与底层转发已经具有验证价值。

## 决定

- 保留 Go wrapper、C++ worker、VPN Extension、启动状态机、配置存储及 URL/文件/剪贴板导入。
- 以 AppRuntime 收敛进程级后台任务、订阅调度和自动恢复，EntryAbility 与首页只承担各自生命周期。
- 删除桌面卡片、卡片共享状态、离线节点解析、旧连接/日志/Geo/关于页面及视觉规范。Geo 资源由构建流程准备，诊断先用日志脚本。
- 原生入口缩为连接、配置、设置；删除节点详情和独立代理 Tab，以单页 REST 组选择保留手动切换。面板验收后删除此临时页。
- 保留网络、少量内核参数设置与配置编辑；Merge/策略转换作为后续独立模块，不把内核参数页当作覆写导入器。
- 文档按操作、参考、决策与证据分工。旧实现和调查过程通过 Git 历史追溯，不维护复制的遗留目录。

## 影响

卡片、离线节点预览和原生高级诊断不再作为宿主功能。已有偏好与配置文件不删除，包名和许可证保留。面板、Smart 和配置事务按独立门槛建设；清理不得被误报为完整产品已实现或真机稳定性已通过。

原始实现可从清理前源码 `77189bc9c9e90c62bc166a23a3a93159dfca27c5` 查阅；基线测试范围见 [P0 证据](https://github.com/Starfie1d1272/Cexing/blob/df757138/docs/evidence/2026-10-12-p0.md)。
