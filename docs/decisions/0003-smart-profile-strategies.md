# ADR 0003：Smart 只变换订阅的生成版本

状态：接受。日期：2026-10-13。关联 #38。

## 背景

订阅的原始 YAML、手动 Selector、规则目标与节点引用是用户策略；Smart 模型已作为官方来源的离线资源随包验证。自动转换和地区入口必须能随订阅更新重建，也必须允许关闭并恢复用户原策略。

## 决定

- 默认开启的基础转换只把生成版本中的 `url-test` 与 `load-balance` 改为 `smart`。用户可关闭；原文和手动 Selector 不改。模型是否在设备上实际参与预测仍由设备验收确认。
- 对没有现成 `smart`、`url-test`、`load-balance` 的订阅，用户可明确创建地区入口。只按节点名称推测地区，并让用户修正未知或错误归属；不推断节点真实地理位置。
- 新入口放在用户指定的原 Selector 内，只指向生成的非空 Smart 组；原规则的条件、顺序、目标不改，不建立回指循环。“仅创建”不改变当前选择；“创建并启用”记录明确的选择请求，Controller 就绪后选取一次，后续手动选择不被更新覆盖。
- `use`、`include-all` 与相关筛选只使用经现有路径保护和校验的本地 provider 快照。快照缺失显示待解析，不做远端下载或把缺失当作空组。生成组空时回退 `REJECT`。
- 策略计划随不可变生成版本记录。关闭时经配置事务移除生成入口，并在原手动选项仍有效时恢复该选项；候选失败保留前一有效版本。

## 影响

生成结果、缓存和选项可在云端用合成配置与锁定 Mihomo 解析器验证。首次安装模型、Controller 选项切换、真实预测与转发、恢复和资源成本仍需要 HoKit 签名后的 Pura 70 Pro 验证；云端 Full 不代替这些设备结论。
