# 组合分流意图

规则所有权、候选范围与选点算法是三个独立维度。原生编辑长期意图，Zashboard 负责运行选点和测速。

## 用户路径与默认值

- 导入后直接沿用订阅连接，无配置前置。分流页面只提供“订阅默认”“策星管理”两种规则所有权；全局覆写仍在订阅顶部 Sheet。
- 订阅默认保留原规则与组；“一键 Smart”只通过既有安全转换把兼容自动组转换为 Smart，保留 Selector、fallback、规则、个人例外。无兼容组时反馈“没有可转换的自动组，可使用策星推荐”，不报告已启用。创建入口仍沿用既有范围预览和明确确认。
- “策星推荐”是一次明确的应用：默认出口为全节点 Smart；初始一条“AI 服务 → 除香港外 · Smart”，AI 与默认共用相同订阅节点来源，未知分类默认排除于 AI，未知计数和手动纠正在出口编辑可见。默认出口包含未知。按名称推断地区不等于实际地域验证，排香港不承诺解锁。
- 出口编辑直接展示 Smart / 自动测速（url-test）/ 顺序回退（fallback）/ 手动选择（select）。范围支持多国家、节点、provider、排除地区和节点；多国直接合并成候选叶节点集合。fallback 显式有序，不能通过 Selector 的单个选择冒充多个国家，也不受全局 Smart 覆盖。
- 专用分流默认折叠为服务、地区摘要、选点方式，点开编辑。AI 聚合涵盖维护库支持的 AI 服务；ChatGPT、Claude、Gemini 等可独立覆盖，也可多服务共用出口。特定服务先于 AI 聚合。Netflix、Disney+、Spotify 等维护库确有分类的服务按需添加，不自动纳入 AI 地域策略。
- 高级规则复用现有规则编辑器，支持域名、IP 网段、规则集和内核接受的其他合法规则；原始配置保留。未知合法字段原样保留，编辑不能借重建对象丢字段。
- 首页未连接不渲染面板入口；连接后在固定上方位置显示。启停按钮继续固定底部，不随入口显隐移动。

## 编译、覆写和失败

原文 → 全局 Merge → 本订阅 Merge → 托管生成 → 个人编辑 → Smart（托管出口算法受保护）→ 宿主平台强约束 → 完整校验 → 原有 preview/revision/digest/stage/apply/publish。

托管只替换规则段并追加自有稳定命名的组；其他原文和高级键保留。启用前明确确认将接管两层 Merge 的规则段；后续全局或本地 rules 覆写与托管冲突时须拒绝或显式重新确认，不能假报覆写生效。平台强约束最后执行。移除管理从原输入重新编译，不反向修改生成 YAML。

规则顺序：局域网直连 → 专用自定义规则和特定服务 → AI 聚合等一般服务 → 国内域名/地址直连 → 默认出口。不默认禁 QUIC 或 UDP。重复服务和非法/循环/悬空引用拒绝。生成实体 ID 稳定，与显示顺序无关；名称碰撞失败。

订阅更新从新来源重新解析候选，不将旧生成列表冻结为 Merge。不递归展开嵌套组或 dialer 依赖；provider 只读已有安全解析快照，不后台下载私人地址。空候选、缺少 provider、排除后为空、规则库缺失或解析失败拒绝发布并保留旧有效运行配置；动态空组使用 REJECT。用户排除地区不能作为隐式回退。

旧 original/region/ai/automatic、归档、Mine/Baseline、Smart 例外和个人操作保持原语义读取。升级不静默转换为推荐；更换所有权沿用依赖分析、归档及确认，恢复旧方案仍可恢复其个性修改。存储兼容适配可以继续读旧 TemplatePlan，但新产品模型须是结构化范围、算法、出口、服务与所有权，不能再让用户在四个不相干模板中互斥选择。

## 规则来源和离线更新

首选 MIT 的 [v2fly/domain-list-community](https://github.com/v2fly/domain-list-community)，固定精确提交，完整递归展开 category-ai-!cn 及其子服务（含 CDN/API/语音），保留声明和原始来源摘要。该分类是维护者的服务分类，绝非服务官方禁香港列表。CN 与其他服务也使用真实维护分类；不宽匹配共享认证或客服域名，不复制私人策略。

生成数据随内核离线可用。更新脚本先下载、完整展开、验证语法/计数/摘要，再一次替换生成数据；失败保留旧资源。更新提交须经过代码审查和 clean HAP，不在手机启动中临时拉取公共或私人规则。MetaCubeX/meta-rules-dat 可作格式/分类参考，不能假定 lite 已包含完整 AI。

## 验证边界

关键回归覆盖：两模式和旧意图保留；Smart 不误转 fallback；多国/排除/未知；特定服务优先与共用出口；更新空范围拒绝且旧指针不变；原文/高级字段/全局 Merge 保留；首页入口和文案。真实 ArkTS 编译与 clean HAP 单列。真机仍需连接/热重载、真实规则命中和实际出口、模型预测、窄屏/大字号/读屏与返回/取消验收；源码或结构图不是设备截图。

托管配置通过 TemplatePlan.routing 兼容信封接入已有稳定编辑绑定和 Base/Mine；templateId=routing 是存储适配标识，不是第五个互斥产品模板。旧归档和操作所有权继续由共同 SwitchTemplate 处理。高级参数的精确边界见[能力矩阵](routing-capabilities.md)。
