# 用户路径与界面契约

## 入口与职责

主入口为连接、订阅、设置。连接页承载状态、唯一启停操作、当前订阅、代理模式与紧凑流量入口；手机已连接时控制面板位于状态卡前，普通首屏可见。Zashboard 承担运行节点、策略与延迟测试；保留首次概览和既有偏好，不复制原生节点选择器，也不将分流配置中的出口选择称为当前节点。

订阅列表顶部保留全局覆写 Sheet。导入 URL、文件、剪贴板或扫码后可直接启用并连接，也可稍后处理；不强制配置模板。详情优先启用、更新、分流方案。定义层的节点与策略组、规则与 DNS、原始配置、本订阅覆写、生成配置收在高级编辑。

设置负责应用运行、订阅自动更新、网络（应用代理与 IPv6）、Smart、必要高级参数及故障排查。单订阅 DNS 只从该订阅高级编辑进入。资源检查与恢复从故障排查的修复资源进入，正常首页或设置页不常驻资源状态。

## 分流方案

使用互斥单选列表，主要操作为应用，次要操作为查看改动。选定必要出口后，应用会内部获取预览，再经原有 revision/digest receipt 和共同事务发布；查看改动是可选操作。预览保存的草稿与 `EffectiveVersions.Profiles` 中已发布方案分开读取，无差异禁用应用。已发布表示保存的方案；真正运行结果以 applied/saved、恢复门禁和当前连接状态为准。

| templateId | 显示名称 | 范围 |
|---|---|---|
| original | 订阅默认 | 按现有停用语义保留个人修改与归档；依赖和重新启用确认仍适用 |
| region | 地区分组 | 选源 Selector；保留订阅规则，生成地区选项供面板选择 |
| ai | AI 专用出口 | 指定 AI 出口组，其余沿用订阅；发布后异步定向检测，结果不承诺解锁 |
| automatic | 基础分流 | 局域网直连，其余走指定出口；替换订阅规则前短确认 |

不新增规则库、组合引擎或第二条发布通道。校验、覆盖、恢复个人修改和停用依赖仍经过原事务。失败保留旧运行配置，并明确新方案未生效；unknown/committed-pending 保持原恢复门禁。

## 关闭与反馈

二级页使用系统导航返回。全局覆写的 ×、下滑和返回使用同一个 Sheet `shouldDismiss` 草稿保存协议：只有保存成功才允许关闭，失败短反馈并留页，busy 拒绝关闭。没有重复关闭或等权手动保存草稿按钮。分流页和更新审阅在事务、确认或恢复期间阻止系统返回；嵌套审阅先返回方案页。

Settings 的刷新事件仅在持久化成功后发出。VpnController 在绑定时捕获发送给该会话的设置，收到同一会话内核就绪后才确认；会话设置回执仅用于展示比较，不参与配置发布。冷恢复只接受 session 匹配的私有回执，回执缺失不能推断设置已应用。比较 IPv6、应用范围、mixed 端口、LAN、日志级别和落盘开关；应用列表按集合比较并忽略宿主自身，全部应用与空排除名单按等价系统策略比较。保活、自动更新、自动恢复和即时代理模式不产生重连提示。改回已应用值即清除差异，取消或接受启动不能伪造已生效。

未连接是正常状态；当前连接检查暂停，离线导出支持包与修复资源仍可用。连接探测在前后核对 configurationEpoch 与 session，迟到结果不能更新新会话页面或被记录为新会话检查。Controller 可达只表示本机服务响应，实际转发仍需独立验证。

## 视觉与操作

复用 NativeTheme 的主操作、次操作、文字危险操作、列表入口、单选与开关样式；按钮与选择器显式主题、至少 44 vp 触区，使用最小高度允许大字号增长。选项同时呈现视觉选择和无障碍选择状态，busy/disabled 禁止重复提交。浅深色保留现有品牌与状态卡设计。

风险只在触发时确认（LAN、敏感备份、替换规则、依赖停用）。必要失败直接给修复操作；技术状态和帮助按需展开。构建、宿主 mock 与真实 ArkUI/转发验收分别记录，不以示意页面代替设备截图。
