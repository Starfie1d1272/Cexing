# 第一轮调研入口

调查日期：2026-10-12。原始基线：`3b141e3bc6050fc081aaccd5f77bf523dd4620cb`。

目标是基于 ClashOH 建立中文优先的轻量 HarmonyOS 原生 Mihomo Smart 客户端。ArkTS 承担系统 VPN、订阅、授权、状态与生命周期，Zashboard 承担策略组、连接、日志和 Smart 权重管理。VPN 生命周期独立于 ArkWeb。

本轮范围是源码审查、环境审计、原始底座构建、Smart 最小试编译、集成方案与文档初始化。显示名称暂时沿用 ClashOH，用户在签名准备阶段确认包名为 `com.starfie1d.mihomo`；后续真机阶段修复了订阅响应、命名和 VPN 启动生命周期，标准内核固定到 v1.19.32。
