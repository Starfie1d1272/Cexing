## IMPORT-001：正常订阅被判定为空

- 状态：已修复，真机首次导入和订阅更新均回归通过。
- 证据：原客户端的激活订阅可用；请求返回 HTTP 200、约 495 KB 的 Clash YAML、Content-Type application/octet-stream。
- 代码：ProfileStore 的导入和更新只接受字符串，未指定 expectDataType，非字符串结果被转为空字符串。
- 修复：两个下载入口显式使用 HttpDataType.STRING，保留原配置校验。
- 隐私：本记录不包含订阅链接、路径令牌、节点或用户配置。

## IMPORT-002：自动配置名称取到 URL 路径令牌

- 状态：已修复，重新导入的真机回归通过。
- 原实现：以 URL 最后一段生成名称；订阅链接采用令牌路径时，令牌被用于配置名称与文件名。
- 修复：优先解析服务端 Content-Disposition 的 filename / UTF-8 filename*；无合法文件名时生成不含 URL 的默认名称。拒绝路径分隔符、控制字符与过长名称。
- 验证：11 项实际 ArkTS helper 测试通过；设备重新导入后自动名称与服务端文件名一致；现有配置的手动重命名已完整替换保存，更新与激活成功。

## VPN-001：首次连接触发扩展生命周期超时

- 状态：已修复，真机连接、停止、重连与浏览器 TUN 转发回归通过。
- 证据：17:05:08 内核开始下载缺失 MMDB；17:05:13 出现 LIFECYCLE_HALF_TIMEOUT_WARNING；17:05:18 connect timeout 并断开；17:06:38 数据库下载超时。
- 修复：onConnect 及时返回，通过 IPC 独立报告内核就绪/失败；启动取消移除系统 VPN 并回收迟到的内核启动。构建时校验并内置首连 GeoIP 快照。
- 真机回归：GeoIP 从 rawfile 铺盘，配置初始化 7ms，TUN 为 gVisor；页面 Connected 后浏览器测试页成功返回，Controller 记录该站点的 Tun 连接和代理链，上下行计数增长。停止后 Controller 不可达，重连后再次转发成功。
- 边界：当前订阅的 IPv4 转发已验收，IPv6、长时间息屏、网络切换与其他订阅资源仍待验收。
