## 真实转发失败的边界

手机浏览器访问 `https://api.ipify.org/`、`https://1.1.1.1/cdn-cgi/trace` 和 `https://www.example.com/` 未得到预期页面。采用隔离测试副本和原有订阅均未取得成功响应。HiLog 存在 TCP 进入规则及代理链的记录，这只证明路由被执行。

另通过临时 HDC 转发访问手机 mixed 端口：HTTPS 请求返回 `SSL_ERROR_SYSCALL`、HTTP 状态 000/下载 0 字节；HTTP 请求返回 502/下载 0 字节。该辅助检查也失败，尚不能将浏览器失败归因于 TUN；节点有效性、解析、上游握手及 OHOS socket 行为仍需区分。没有将此代理端口检查写作 TUN 通过。

这类失败未取得对应的有界内核错误摘要，现有“内核就绪”诊断无法定位原因。修复入口与验收条件见 [独立云端任务](../../../integration/first-test-cloud-tasks-20261013.md)。

Go 下载遇到 EOF/HTTP2 错误，本次使用只读已有下载缓存、镜像和进程级 HTTP/1.1 重试，完整性检查保持执行。面板字体镜像包的 SHA-512 与冻结锁相同。Mac 功能资源与 main 摘要一致，许可清单因平台可选依赖产生差异；按 Linux/glibc 依赖清单复原后，许可文件大小和 SHA-256 精确匹配 main 的原锁。应用源码和资源锁均未修改。跨平台许可清单生成应另行做可复现构建修复。
