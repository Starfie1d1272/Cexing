# 首个原生 UI 测试包：设备验收清单

以下均为**待本地验收**，云端没有操作设备。安装与签名步骤沿用[设备指南](../../how-to/device.md)；HoKit/Hokit 重签前核对包名、设备范围及下载包摘要。不要用卸载或清空数据绕过升级问题。不要在公共反馈中上传订阅 URL、节点、凭据或原始配置。

- [ ] 记录 PR head、HAP SHA-256、HoKit/Hokit 签名后包摘要、手机系统/API 版本、窗口宽度和系统字号。
- [ ] 从空配置启动：固定“连接 / 订阅 / 设置”三页签，无大占位图标；首页导入按钮可达。
- [ ] URL 导入失败保留输入，可重试；成功后确认启用或稍后启用。文件导入和剪贴板权限拒绝后的手动 URL/YAML 粘贴均可用。
- [ ] 列表 → 订阅详情 → 返回；启用、更新、重命名、编辑、另存、导出后，列表与当前订阅同步；用长名称检查换行与省略。
- [ ] 删除取消保留文件；删除非当前订阅成功；运行中的当前订阅要求先断开，不能直接删除。与浏览器原型“自动断开再删除”有明确差别。
- [ ] 拒绝系统 VPN 授权后可重试；启动中取消；错误配置进入失败；系统授权来自 OS。
- [ ] 已连接的白色状态场、灰黑斜面、青色接缝与黑色速率带符合确认参考；实际流量停止更新超过 4 秒显示“—”。
- [ ] 连接中、已连接时切换页签/进入节点页/诊断页/返回，VPN 不中断；离开连接页关闭展示 WS，返回重新订阅。
- [ ] 旧断开确认打开后由外部操作断开并重连，旧确认不能停止新会话；切页/进入二级页/离页再返回后的旧确认同样无效。
- [ ] 合法命名“未导入.yaml”或“未导入.yml”的激活配置，仍显示状态、诊断与连接/断开操作；空选择显示导入态。
- [ ] 断开取消保持连接；确认断开只作用于仍连接的会话；停止完成后速率清空。
- [ ] 模式切换及 Selector 节点选择使用实际控制面；自动组（包括 Smart）不出现固定节点操作。
- [ ] 设置开关持久化，自动更新开启后可选 12/24/48/72 小时；间隔触区 ≥48vp；网络设置包名添加/删除与 IPv6 保留。
- [ ] 内核参数覆写输入非法端口不会保存/恢复成默认值；修正后点击保存，下次启动生效。订阅 Merge 尚未接入，不能把参数页当成 Merge。
- [ ] 诊断检查显示真实 Controller 可达性；状态变化或离页后迟到的检查结果不覆盖当前状态。“系统会话 / 真实转发”保持待设备确认。
- [ ] 窄屏、横屏、700vp 以上窗口和大系统字号下，关键文字不与斜面相交；设置/网络/详情可滚动；键盘不遮住提交；系统返回正确退栈。确认底部安全区与无障碍朗读。
- [ ] 分别采集**实际原生**的空首页、已连接、订阅详情、导入错误、设置间隔、参数端口错误、诊断截图，记录设备与对应源码/HAP身份。
- [ ] 按设备指南验证浏览器真实 TUN 请求、代理链与双向字节，另测 DNS/UDP、IPv6、Wi-Fi/蜂窝切换、息屏 15/30 分钟和关窗恢复。

面板路由保留，但当前 main 安全门禁没有提供可用 session/首页入口；本 UI PR 不开启面板，不实现 Smart 或配置事务。集成负责人完成这些接点后，另验收面板返回/关闭/错误不停止 VPN，以及离线 REST/WS、认证拒绝、配置回退和 Smart 实际预测链。云端页面测试、编译与截图参考均不代替这些门槛。
