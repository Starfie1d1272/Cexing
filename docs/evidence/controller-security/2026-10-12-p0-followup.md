## 修复与边界

1. UI 错误从 startController 的致命返回改为静态 404：目录根、整个 UI 树的 symlink/特殊文件、当前选择器、选中版本 manifest 身份与文件摘要/全集均检查。降级根位于已验证的普通 credential 文件下面的不可遍历子路径，锁定 HTTP Dir 把 ENOTDIR 转成 404；不调用 SetUIPath(空字符串)，不把私有 homeDir 当静态根。GET /ohos/ui-status 返回受认证的初始化状态和通用可恢复提示，API/VPN 初始化继续。
2. 平台默认/最终约束只保留一个 projectPlatformConfig 实现：删除顶层 Controller secret 后可供配置线持久化；运行态 enforcePlatformSecurity 调用它，再在内存中注入随机 Secret。未把注入后的 map 提供给 candidate、成功版本、diff/回执或日志。独立包 #5 的生产适配与存储保护仍由配置作者落实，未宣称已合流。
3. 上游 ReCreateServer 启停均启动 goroutine，关闭没有完成回执；HTTP Server.Close 明确不关闭 Hijack 的 WS。宿主改为一个同步 Listen 与自有 Server/已接受连接集合，停止关闭 HTTP 和 WS、等待 Serve 循环退出；强制终止升级连接避免 TCP 半关闭后的缓冲写入。旧会话排队的 PUT/PATCH 取得运行锁后再次核对代次。没有用 sleep 或端口重试宣称 stop 完成。
4. 保留上游所有 REST/WS handler、认证及 Register 扩展路由，通过 go:linkname 绑定锁定 v1.19.32 的私有 router 工厂。没有复制 API 实现、改模块缓存、改依赖、增加第二个 HTTP 服务或关闭 Go 链接检查。这是新增且明确的私有 Go 耦合；后续内核升级必须核对签名和链接/生命周期回归，不能把当前通过当作所有候选内核已验证。
5. 上游 executor 对非空 ExternalUI 会触发 AutoDownloadUI 即使 URL 为空。运行态 cfg.Controller.ExternalUI 置空关闭该 updater；宿主仍显式设置已校验静态根。这与禁止 SetUIPath(空字符串) 不矛盾，也没有让重载重新开启危险 UI。
