# 策星 · Cexing

策星是面向 HarmonyOS 的原生代理客户端。日常连接与配置在原生界面完成，深入观察与策略操作交给 Zashboard；Smart 在用户设定的策略范围内辅助选择路径。

正式中文名称为“策星”，英文名称为“Cexing”。工程目录为 `cexing/`，应用身份为 `com.starfie1d.cexing`，VPN 扩展为 `CexingVpnAbility`。通用模块按职责命名，Mihomo、Zashboard 与 Clash 配置生态保留真实技术名称和来源声明。

界面沿用黑白灰、青色和克制几何。状态、操作与错误使用可理解的语言；专业细节按需展开。Logo 与正式应用图标独立设计，现有资源作为占位。

功能宣传以实际验收为依据。内核就绪、模型加载、实际预测和真实转发分别验证。内置模型、一键启用及默认策略的开发在 Issue 中跟踪。

品牌更名会创建新的应用身份。旧开发包的数据保留在旧沙箱，用户可通过原应用导出配置，再导入策星；不得通过卸载或清空旧数据完成迁移。调试签名 Profile 必须匹配新包名。磁盘内的 `clashoh_settings` 偏好键保留为数据格式兼容标识。
