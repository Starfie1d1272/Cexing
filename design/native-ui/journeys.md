# 信息架构与用户旅程

## 单一职责

| 位置 | 用户任务 | 交接 |
|---|---|---|
| 原生·连接 | 授权、VPN 启停、系统/内核状态、有效订阅、错误恢复 | 内核就绪后进入面板 |
| 原生·订阅 | URL/文件/剪贴板导入，来源更新，覆写选择，预览、启用与回退 | 全部经过同一配置事务（目标） |
| 原生·设置 | 更新偏好、恢复偏好、系统授权说明、诊断 | 保留实际高级网络能力，实施时仍由宿主处理 |
| Zashboard | 节点、策略组、Smart、连接记录、规则、内核日志 | 原生只提供返回与宿主错误边界 |

「VPN 连接」与面板的「连接记录」含义不同。原生不新增节点列表、组选择器、规则编辑器或 Smart 开关，不扩建临时 ProxyPage。原生诊断只展示宿主状态与脱敏故障摘要，内核日志留在面板。

## 关键旅程

| 触发 | 操作与结果 | 失败或取消 |
|---|---|---|
| 首次进入 | 添加订阅 → 选择 URL/文件/剪贴板 → 显示名称 → 继续 | 演示不读真实输入；生产需私有存储来源 |
| 普通导入 | 沿用订阅 → 完整校验 → 差异预览 → 启用 | 校验失败显示类别与修复动作，不替换有效配置 |
| 高级导入 | 选择覆写 → 编译、平台保护、完整校验 → 差异 → 启用 | Merge 语义与可移植策略尚待实现，不执行脚本 |
| 首次连接 | 宿主解释 → 系统真实授权 → 建立会话 → 等内核就绪 | 拒绝/返回后保留订阅，用户可以重新授权 |
| 启动进行中 | 显示阶段，主动作「取消连接」 | 取消撤销待恢复，迟到就绪不得恢复已取消会话 |
| 内核就绪 | 允许断开与打开面板，转发健康独立显示 | Controller 可达不能显示「网络正常」 |
| 启动失败 | 显示脱敏错误类别 → 重试/诊断/恢复设置 | 保留有效配置；不静默无限重试 |
| 更新订阅 | 更新 → 重新应用覆写 → 校验 → 应用成功切换有效版本 | 应用失败仍显示上一有效版本，允许重试 |
| 打开面板 | 原生返回入口 + Web 宿主 | 资源/认证失败在宿主展示，返回、关闭不停止 VPN |
| 修改恢复偏好 | 明确「打开应用自动恢复」，说明只恢复成功会话 | 主动断开/取消优先于自动恢复 |
| 恢复显示偏好 | 二次确认 → 主题/深度回到默认 | 不删除订阅、不改变恢复开关，取消不改变任何设置 |
| 诊断与摘要 | 分别呈现系统会话/Controller/实际流量 → 摘要预览 | 未验证显示「待验证」，不展示 URL、secret、完整配置 |

原型支持以上旅程的关键可点击路径。更新、校验、授权、运行、诊断和面板全部是显式演示结果；未接入真实配置事务、系统授权、Mihomo 或 Zashboard。导入三个入口仅切换合成示例，没有系统文件选择器或剪贴板读取。设置不写持久存储。诊断摘要只预览，没有实际分享动作。

## 状态与导航

| 状态 | 主按钮 | 页面表达 |
|---|---|---|
| 无有效配置 | 添加订阅 | 先配置再连接 |
| Disconnected | 连接 | 未连接 |
| 授权未完成 | 重新授权 | 当前未连接，配置保留 |
| Connecting | 取消连接 | 已完成阶段 / 等待阶段，不以百分比虚构进度 |
| Connected | 断开 | 内核就绪，系统会话信息与流量健康分开 |
| Disconnecting | 请稍候（禁用） | 防止重复启停 |
| 启动失败 | 重试 | 持续可读错误卡片，避免只用短暂 toast |

失败是视图状态，不建议新增同名 VpnStatus 枚举。实际启动阶段必须有运行时证据；现有源码只有粗粒度状态时使用「连接中」，不要假报系统会话已建立。冷恢复只有 Controller 活着时需「会话待确认」，不能直接标内核就绪。

底栏始终可达，主体独立滚动。连接页上的「当前订阅」进入订阅页。二级页返回父级；切换页签和返回连接页不改变 VPN 状态。原型在连接中提供两枚演示结果按钮，生产界面应删除；真正的取消仍由生命周期接口执行。错误恢复主动作优先，长诊断摘要可滚动；360 宽无需横向滚动。

## 面板衔接

使用原生返回区、相同安全边距与系统深浅色过渡，内容区保持 Zashboard 自身排版。不要注入覆盖整套面板的 CSS。进入时先核对资源版本、内核状态与认证，认证凭据在宿主内部传递；地址栏/导航历史/截图不出现 secret。面板关闭仅释放 WebView 展示资源。原型「面板宿主」是交接占位画面，不能当作真实 Zashboard 渲染证据。
