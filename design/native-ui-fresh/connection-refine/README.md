## 浏览器审查与验证

实际 Chromium 渲染并查看 390×844、960×720 与 360×780；另验证 430×932。首轮发现 360×780 面板入口与固定动作区冲突，已用短屏主卡重排修复。图形首轮桥线悬空，改为连续贯通两端，减少“短划线装饰”的感觉。

`python3 design/native-ui-fresh/connection-refine/verify.py`：4 组前后状态与文本相同、24 个状态/窗口、8 个订阅/设置逐像素一致比较；取消迟到回调、连接、返回保持会话、断开、减少动态效果通过；无浏览器异常或横向溢出。脚本还核对前稿三个运行文件与 Git 7c58539 字节一致。PNG 直接来自浏览器，不是生成效果图。

Skill 目录审查已运行；动态选择器警告来自运行时生成 DOM，已由浏览器确认存在。数值色彩用少量现有中性色，保留其 token 建议作为实施阶段工作。未运行 HAP 构建，因为本轮没有原生源码变动；浏览器截图不构成设备端实现验证。
