## 动效准确说明

**3f5e300 大图形没有循环动画。** 两侧端口定义了 `transform 240ms` 过渡，但 render 会重建图形，状态切换并不能可靠播放这个过渡；不可将这段 CSS 当作已经实现的连通动画。连接中显示灰桥，已连接显示青桥，断开时端口分离。

实际持续动画是状态文字前的 `.spinner`：旧稿为旋转方框，`spin 1s linear infinite`，仅在 connecting / disconnecting 存在。点击“连接 VPN”触发 connecting；点击“断开连接”再确认触发 disconnecting；操作完成或取消后移除。前稿与新稿的浏览器 `document.getAnimations()` 都只检测到该 spin；减少动态效果时检测到零动画，文字仍可读。

**新稿的三层主卡块面完全静态。** 仅将必要的小加载标记改为圆环，保留其原有旋转反馈，不新增主卡位移、扫光、呼吸或环境循环。已连接接缝青色，其他状态灰色，随状态重绘；这是状态差异，不是动画。

GIF 是 390×844 浏览器约 5 秒实际截图连续记录，真实点击“连接 VPN”→“断开连接”→“确认断开”。记录原型的合成操作时长（连接 1500ms、断开 700ms），没有延长操作来制造效果；PNG 是静态实图，不用它声称展示动效。实际点击时间与帧数见 evidence.json。

## Skill 对应的设计改变

继续使用已安装固定版本 `0b22e94f025282dc3372469f278ac9d13da6a079` 的 **Ark + minimal**，结合最近完整阅读的 Ark recipe、design-language、depth-levels、family-depth-matrix、frontend-evidence 与 source-ledger。高层参考是账本中 [Arknights 官方入口](https://ak.hypergryph.com/) 的非对称主场、边缘数据、黑白灰层次与青色信号；不照搬具体 Logo 或媒体素材，也不把网站布局当作原生框架实现。

| 视觉语法 | 本稿的具体作用 |
| --- | --- |
| Stage + instrumentation | 状态文字占白色主场，真实既有速率仍归底部数据带；没有新增遥测或说明 |
| 非对称平衡 | 灰色斜面与黑色楔面停靠右缘，给左侧中文留下清晰负空间 |
| 局部裁切、层叠平面 | 斜面从圆角外延入，黑色楔面与数据带连续；不再形成独立可识别的连接图标 |
| 单一受控信号 | 一段青色接缝表达已连接，其余大面积为白、浅灰与炭黑 |
| Minimal 的克制 | 无索引、条码、角标、英文装饰、图案纹理或新增环境动画；保留浅底圆角三页签 |

## 看图与验证

自行查看 390×844、960×720、360×780、连接中和网络错误实图，确认文字与斜面不相交，手机面板入口在固定动作区之上，展开态由主卡／工具两列保持布局。圆角外轮廓不改，斜切只发生在卡片内部。

`verify.py`：4 组同状态同文本前后截图，24 个状态/窗口检查，8 个订阅/设置逐像素一致比较；取消迟到回调、连接、跨页返回保持会话、断开、减少动效通过；无浏览器异常或横向溢出。前稿三个运行文件与 Git 3f5e300 字节一致。Skill 审查无错误；动态 DOM 静态识别及色彩 token 建议见 skill-audit.json。

复现：仓库根目录运行 `python3 -m http.server 8765`，执行本目录 `verify.py` 和 `capture_evidence.py`。脚本依赖 Python Playwright/Pillow 与 Chromium，截图使用原型自有合成状态。没有实际连接系统 VPN，也没有运行设备端材质/转发测试。

## 后续实施

如果选此稿，原生实现只需状态文本层、两片裁切中性面、接缝信号和速率带，不需要图标动画资源。裁切以主卡尺寸推导，避开文字安全区，窄屏保持触区；状态由 AppRuntime 提供，页面不拥有 VPN 生命周期。加载环使用系统可用控件并遵从减少动态效果。端到端系统授权、原生材质与设备字体仍按既有能力矩阵验收。
