## Skill 安装与设计契约

按 [Ark UI 官方安装说明](https://github.com/Brandon030722/ark-ui-skill#安装) 实际克隆安装，固定提交 **`0b22e94f025282dc3372469f278ac9d13da6a079`**。系统 `$CODEX_HOME` 只读，因此使用本云任务独立技能目录的 `skills/ark-ui` 布局；未修改系统目录或环境变量。安装在公开交付目录外。

已完整阅读 `SKILL.md`、design-language、depth-levels、Ark recipe、family-depth-matrix、frontend-evidence、source-ledger、legal；审查五个脚本及 agent 元数据。脚本仅包含本地复制、启发式审查、公开 CSS 提取和浏览器截图逻辑，没有安装时执行的 hook。实际运行审查脚本，截图使用本任务原创 Playwright 流程。没有复制 Skill 代码、模板、图片、字体、宣传素材或官方生产资源到交付物。

**契约：鸿蒙原生轻盈，融合 Ark minimal 的秩序与层次。** 新版依据真实原生应用和官方控件示意，采用浅色圆角、胶囊操作及悬浮导航；具体观察见 [视觉研究](VISUAL-RESEARCH.md)。保留的硬边版本从 Skill 来源账本中 Arknights 的黑白壳层、青色状态线、矩形动作和单一信息所有者推导；参考链接为 [官方入口](https://ak.hypergryph.com/) 和 [新闻列表](https://ak.hypergryph.com/news)。这是来源账本记录的设计模式，不把旧调查当作今天的在线事实，也不声称官方授权。Ark 指鹰角审美方法，与 HarmonyOS ArkUI 框架不是同一概念。

布局从本产品任务重新组织。minimal 用于新信息架构的识别层，固定保留“连接 / 订阅 / 设置”三个原生页签。moderate 对照只加黑色顶部边缘壳层与一组低对比纵向分隔线，不增加功能或数据。无画作、品牌符号、科技仪表、虚构系统编号或环境动画。

- 三个固定根入口：连接 / 订阅 / 设置。导航独立停靠视口底部，不随主内容滚动；二级操作进入页面栈。页面切换不停止 VPN，也不取消正在进行的连接。
- 一层主路径：首页状态 → 唯一连接 / 断开操作；主动作固定在页签上方，状态卡只保留标题与一条状态信息。弹层打开时遵循 modal 焦点隔离，关闭后恢复三个页签可操作。
- 一个数据所有者：VPN 状态在首页；订阅用量只在详情；节点 / 组 / Smart / 连接 / 规则 / 日志属于 Zashboard。
- 新版以一种深水青色标识状态、选中与主动作；错误使用功能性红棕色。硬边对照保留原青色左缘。
- 触区至少 48px，主动作通常 56px；正文 14–16px，状态标题 36px，元数据 12–13px；设置按关联任务组成圆角分组。高度受限时重排状态 / 速率，不缩小触区。
- 新版卡片 24–28px、胶囊按钮 28px、弹层 32px，按原生偏好确定，不机械继承 Skill 的硬边几何。系统弹窗只是示意，最终使用 OS 原生授权，不能自绘代替。
- 页面内容滚动，底部主动作保持可达；窄屏不缩小关键文字。焦点可见、modal 焦点受限、背景 inert、Escape / 返回关闭、减少动态效果。

## 任务与流程

| 任务 | 原型路径 | 关键状态 / 行为 |
| --- | --- | --- |
| 首次 URL 导入 | 首页 → 订阅链接 → 表单 → 确认 → 启用 | URL 格式错误保留输入；示例填充不请求网络；超时可重试 |
| 文件 / 剪贴板 | 首页 → 配置文件 / 剪贴板 | 文件选择读取本地文本、32MB 限制；剪贴板采用显式手动粘贴，不假设跨应用读取权限 |
| 覆写 | 确认 / 详情 → 覆写 → 不使用 / Merge YAML | 默认保留原样；Merge 标注方案预览；草稿与差异演示；宿主参数单独设置 |
| VPN 授权 | 启用后首页 → 连接 VPN | 暂不允许保留配置，再次连接重新请求；授权成功进入连接中 |
| 连接 / 取消 | 首页 → 连接中 | 连接中可取消，迟到回调不把已取消状态改成成功 |
| 实时状态 | 首页已连接 | 内核已就绪与真实网络健康分开；上传 / 下载合成流量单一区域 |
| Zashboard | 已连接 → 打开 Zashboard | 仅演示原生到 WebView 交接，不仿造面板控制；加载失败 VPN 保持连接；返回不停止 VPN |
| 订阅更新 | 当前订阅 → 更新订阅 | 更新中禁重复提交；失败保留上份演示状态，重试成功后时间变为“刚刚” |
| 网络中断 / 恢复 | 评审入口 → 网络中断 → 诊断 → 返回 → 重新连接 | 用评审页“演示网络恢复”恢复网络条件，随后由用户点击重试；不在生产页面塞故障模拟按钮 |
| 断开 | 首页 → 断开连接 → 确认 | 独立断开中状态，完成后面板入口禁用 |
| 设置 / 诊断 | 底部设置页签 → 设置 / 诊断 | 宿主开关、IPv6、按应用分流、端口、日志等级；诊断分系统会话 / 内核 / 控制面 / 网络验证 |
| 删除 / 导出 | 订阅详情 → 删除 / 导出 | 当前会话先断开再删除；导出内容为明确标识的合成 fixture |

评审状态采用 `index.html?state=connected&variant=native-light`；`variant=classic` 保留原版，经典方案可加 `depth=moderate`。其他值见评审下拉框；QA 不写入 localStorage、IndexedDB、文件系统或应用沙箱，也不删除存档。网络恢复由 `prototypeQA.setNetworkError(false)` 改变内存条件。它是原型评审接口，不进入生产。

## 现有能力与规划交互

依据 main 的源码与契约核对，不能把原型中的走通视为生产功能已实现。

| 能力 | main 的真实现状 / 来源 | 原型与实施边界 |
| --- | --- | --- |
| 导入与元数据 | `ProfilePage.ets` / `ProfileStore.ets` 支持 URL、文件、剪贴板、来源更新、激活、重命名、导出、删除 | 重排入口，保留原数据格式；原型文件检查不是完整 Mihomo 校验 |
| VPN 启停 | `VpnController.ets` / `ClashVpnAbility.ets` 有四态和扩展就绪回报 | 新 UI 对接状态机；连接 / 断开中保持后台资源，用户取消过滤迟到结果 |
| 流量 | `HomePage.ets` / `CoreApi.ets` 有 `/traffic` WS | 页面可见时订阅，离开释放展示资源，不停止 VPN；断流显示“—”，不保留陈旧速率 |
| 后台与更新 | `AppRuntime.ets`、`LiveViewKeeper.ets`、`AutoUpdater.ets` 已有进程级运行 / 调度 | UI 只显示与修改偏好，不拥有生命周期；自动更新只在内核运行期间按间隔检查 |
| 内核参数 | `OverridePage.ets` 的端口、日志等级、LAN；`NetworkSettingsPage.ets` 的 IPv6 / 手动包名 | 与订阅 Merge 分开；当前参数下次启动生效，不能宣称热生效 |
| 统一配置 / Merge | [配置契约](../../docs/reference/configuration.md) 为目标；当前非完整解析或合并实现，下载 / 热重载未统一 | 原型仅展示方案；实现前先有事务、校验、平台强约束、失败回退 |
| Zashboard / Smart | [集成契约](../../docs/reference/integrations.md) 待接入；现有 `ProxyPage` 是临时组入口 | 原型只展示交接占位；通过 REST/WS / 离线 / 生命周期验收后删除临时页，不扩建原生组控件 |
| 健康 / 诊断 | 源码 Connecting → Connected 表示就绪；冷启动 Controller 探活不证明系统 TUN | 分层健康探测、摘要分享是规划；不得用 UI 正常 / 速率动画声称真机转发通过 |

## 后续实施建议

1. 先定义 UI 状态快照：系统会话、内核就绪、控制面、流量新鲜度、配置应用结果分别表达。保留 AppRuntime 单一拥有者；Native 页面订阅而不启停后台任务。
2. 完成 Controller 回环与统一认证，然后实现原始订阅 → 覆写 → 平台约束 → 完整校验 → 差异 → 保存 / 激活的配置事务。更新失败保留旧配置和原始输入，运行应用失败也回退。
3. 按 [版本矩阵](VISUAL-RESEARCH.md#原生能力与版本矩阵) 对 API 21 基础控件、API 23 HDS 与 API 26 材质选项分别守卫；先有纯色圆角回退，再接原生增强。将布局翻译为 ArkTS 固定三页签、`Navigation`、列表、按钮、原生 sheet / dialog 与安全区。触区与字号不按 CSS 像素机械换算；验证系统字体 / 无障碍字号 / 键盘遮挡 / 长配置名。
4. 接入固定版本离线 Zashboard，使用共享 Controller 认证与 ArkWeb，限制外部导航与 bridge，禁止不合宿主生命周期的 restart。返回、关窗、面板出错均不停止 VPN；验收后移除 ProxyPage。
5. 再实现健康检查和脱敏诊断摘要。真实设备验证拒绝授权、连接取消、启动失败、更新失败回退、息屏后台、网络切换、低流量、UDP / DNS / IPv6；本原型浏览器测试不替代它们。

原型交付不需要把第三方素材重新分发。所有 HTML / CSS / JS、线性 SVG 图标和截图由本任务原创；字体仅用环境系统字体，无字体文件入仓。
