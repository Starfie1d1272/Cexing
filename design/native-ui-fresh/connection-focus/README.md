## 主要构图取舍

- **一个有主次的连接区域**：左侧状态是第一阅读点；右侧两端相连的原创几何图形尺寸更大、对比更低，辅助理解连接而不争抢文字。
- **把速率纳入主卡**：原先分散在卡片下面的上传 / 下载收进同一主卡下区。上区为白色，下区以局部深色块面对比承托现有数值；没有恢复整块黑色状态面板。
- **用错位形成整体轮廓**：几何连接两端斜向错位，状态文字与图形形成左右不对称，速率区域提供共同底座。识别来自构图，而不是散落短杠、编号或小符号。
- **日常工具的稳定性**：浅底、圆角、舒展边距、主按钮位置与固定三页签保留。连接导航保持原电源图标；订阅、设置与其他二级页面不重设计、不加品牌名。

没有新增数值、遥测、英文装饰标签、条码、图表或控制项。所有文本与状态仍来自冻结原型；图形只表达两端接通。连接中做轻微位移，减少动效时静态显示，连接文字与取消操作仍可用。
