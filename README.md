# 策星 · Cexing

为 HarmonyOS 打造的开源原生代理客户端，让日常连接简洁，让复杂策略可控。

原生界面负责系统连接、订阅和日常管理，Mihomo 提供代理与 Smart 策略，内置 Zashboard 提供深入控制。模型使用条件见 [Smart 指南](docs/reference/smart-beta.md)，功能问题与设备验收在 [Issues](https://github.com/Starfie1d1272/Cexing/issues) 跟踪。
